🤝 Como trabalhamos

Acreditamos que bons resultados são construídos por equipes organizadas, comunicação transparente e processos bem definidos.

🌿 Fluxo de desenvolvimento

Sempre que aplicável, incentivamos um fluxo de trabalho baseado em branches e Pull Requests:

1. "main" — versão estável do projeto.
2. "develop" — integração das funcionalidades em desenvolvimento, quando adotada pelo projeto.
3. "feature/*" — desenvolvimento de novas funcionalidades.
4. "fix/*" — correções de defeitos.
5. Pull Requests — revisão e validação das alterações antes da integração.

Os nomes das branches e as regras de integração devem respeitar as convenções definidas em cada repositório.

👥 Como colaborar

Quer participar do desenvolvimento de uma solução ou contribuir com um projeto?

1. Explore os repositórios públicos disponíveis.
2. Leia a documentação e identifique os objetivos do projeto.
3. Consulte as Issues para conhecer as tarefas e necessidades existentes.
4. Siga as convenções de código, branches e commits definidas pela equipe.
5. Abra um Pull Request quando sua contribuição estiver pronta para revisão.

O acesso para contribuir em repositórios privados depende das permissões concedidas pela organização.
